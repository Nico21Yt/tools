# Tools

收藏的好用工具和 repo。

## 怎么添加

- **随时随地（手机也行）：** [新建 issue → 添加工具](https://github.com/Nico21Yt/tools/issues/new?template=add-tool.yml)，填链接和分类，提交后 GitHub Actions 自动加到下面对应分类，并关闭 issue。描述留空且是 GitHub repo 时，自动用 repo 自己的简介。
- **让 agent 加：** 「把 <链接> 收藏到 tools，分类 AI 与 Agent」。

格式：`- [名称](链接) — 一句话说明`
